# Public mirror note

This folder is a public-safe code and evidence index for the Light Equity research sprint. It contains the refactored pipeline, configuration contract, tests and non-geometric paper-support summaries so that a web-based reviewer can inspect what changed.

It intentionally excludes source CAD, SketchUp, OBJ, DXF and Radiance intermediate files, sensor-coordinate tables and full site geometry. The runnable full package remains in a separate private checkout; the private source data must be supplied separately on an authorized machine.

The metrics in `paper_support/PAPER_NUMBERS.csv` are real outputs from the clean run, but the claims ledger defines their scope. Do not infer universal accuracy, human-design superiority or full-site high-fidelity coverage from the public summary. The private source and run directory are not required to inspect these aggregate results.
