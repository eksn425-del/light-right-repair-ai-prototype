# Public Paper Assets

This directory contains the public-safe subset of the final SOICT paper
package. It is tied to `soict-2026-write-ready-v1` and the frozen run
`baseline_20260909_clean`.

Use the captions and table CSVs as the paper-production hand-off. The complete
package, including geometry-sensitive Figures 2 and 5 and Tables 1, 3 and 4,
is held in the private repository
`https://github.com/eksn425-del/soict-2026-paper-assets`.

No raw CAD/DXF/DWG/SKP/OBJ, sensor coordinates, Radiance intermediate, or
unauthorized real raw data is included here.
