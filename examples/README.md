# Examples

This folder contains public-safe geometry examples for testing the workflow.

## Single Mass Block

Run:

```bash
python main.py --obj examples/single_mass_block.obj --overwrite-obj-dataset --diagnosis-only --output-dir outputs/single_mass_check
```

This example proves that standalone OBJ import works. It is intentionally minimal and should not be interpreted as a real urban light-right repair case.
