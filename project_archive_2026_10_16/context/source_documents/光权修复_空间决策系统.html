光权修复：面向城中村节点微更新的空间决策系统

以“诊断层—决策层—验证层”三层方法，重构居住采光、街道采光与安全通行之间的平衡关系
适用方向：空间计算 / 数字孪生 / 计算设计 / 建筑与计算机交叉研究

一、核心结论

这个项目最稳的定位，不是“我会做光照分析”，也不是“我会做一条更亮的路径”，而是：

构建一套面向城中村节点微更新的“光权修复决策系统”，通过光环境诊断、最小干预体块重组和安全约束流线验证，量化支持空间改造方案。

这样一来，项目的创新核心就不再落在常见插件已有的分析能力上，而是落在如何把分析结果转化成空间修复决策。这与鼓浪屿项目形成了明确的逻辑延续，但方法论发生了明显升级。

二、为什么原版 A / B / C 需要升级

问题 1：如果算法A只是基于模型做日照分析，那和 SU、Rhino、Revit 的现有插件高度重合，创新性不够。

问题 2：如果算法B只是在原有高密环境上继续加方块，可能会加剧遮挡，逻辑上站不住。

问题 3：如果算法C只追求“更亮”，可能会让老人、儿童去走更绕、更陡或更危险的坡道和桥，缺乏伦理与功能上的稳健性。

因此，更成熟的表述应该是：

  • 算法A不是创新核心，而是基础诊断层
  • 算法B不是单纯加建，而是“减法 + 加法 + 重组”的最小干预修复算法
  • 算法C不是纯趋光，而是安全约束下的多目标路径验证算法

三、项目核心问题

城中村中“光权—密度—安全”三者冲突下的微更新决策问题。

这句话比“采光不好”或“流线单一”更准确，也更有研究价值。它意味着项目真正要解决的是：

  • 如何在不大拆大建的前提下完成空间修复
  • 如何通过最小体块调整和有限新模块植入，同时改善居住采光与街道采光
  • 如何在新增连桥、平台、灰空间节点时，仍保障老人、儿童与普通居民的安全通行
  • 如何把这些判断过程变成可解释、可量化、可复用的空间决策依据

四、三层算法框架

1. 诊断层：算法A——光权诊断算法

定位：问题识别器，不作为核心创新，而作为整个系统的输入层。

输入
  • 现状体块模型
  • 节点位置与周边关系
  • 时间参数与基本朝向
  • 街道、立面、窗面基础信息
输出
  • 底层街道受光分布
  • 立面 / 窗面受光时长
  • 阴影压抑区识别
  • 潜在光通道位置

关键意义：不是为了证明“我会做日照分析”，而是为了识别哪里最差、哪里值得修、哪里具备被释放成光通道的潜力。

2. 决策层：算法B——最小干预体块重组算法

定位：整个项目真正的创新核心。

它不只是“加模块”，而是三类操作联合发生：

  • 减法：切角、退台、拆违、打通缝隙
  • 重组：局部功能重新排布、灰空间腾挪
  • 加法：插入方盒子、红桥、平台、公共节点

它面对的不是“空白场地”，而是一个已经拥挤、遮挡严重、结构复杂的既有环境。算法的任务不是随便堆盒子，而是寻找“以最小代价换取最大改善”的空间重组策略。

总得分 = 居住采光提升 + 街道采光提升 + 流线多样性提升 + 公共活动面增加 - 原有功能损失 - 新遮挡惩罚 - 结构改造成本 - 安全风险惩罚

适用场景：局部节点更新、缝隙空间修补、小尺度增改建、灰空间重组、立体连桥介入。

3. 验证层：算法C——安全约束的多目标路径算法

定位：验证设计方案是否真正改善居民通行体验，而不是为了“造一条最亮的路”。

它遵循“先硬约束，再软优化”的原则：

硬约束
  • 坡度超过阈值不能走
  • 台阶过陡不能走
  • 通道净宽不足不能走
  • 无护栏高处不能走
  • 夜间照明不足不能走
  • 对老人儿童不安全不能走
软优化
  • 光照时长
  • 阴影压抑感
  • 拥堵程度
  • 绕行成本
  • 与目的地距离

因此，桥只是候选路径之一，而不是强制路径。没有桥时，算法在地面网络中寻找最优走法；有桥时，只有当桥更安全、更舒适、更明亮时，算法才会选择它。

五、与鼓浪屿项目的区别与延续

鼓浪屿项目
  • 核心问题：信息理解错误 + 路线选择困难
  • 核心方法：语音语义纠错 + 安全地图导航
  • 核心目标：帮助特殊人群在既有环境中更好地走
光权修复项目
  • 核心问题：空间本体不合理 + 光权与安全冲突
  • 核心方法：光权诊断 + 体块重组 + 安全约束路径验证
  • 核心目标：不是让人适应空间，而是让空间变得更适合人

两者的关系不是重复，而是研究对象从“人在空间中如何通行”升级到“空间本身应如何被修改”。这是连续性，不是复刻。

六、最终建议的三大创新点

  • 创新点 1：不是做光照分析，而是建立“光权诊断—修复—验证”的闭环系统
  • 创新点 2：提出“最小干预体块重组”而非单纯加建，回应“越加越挡”的现实问题
  • 创新点 3：把安全作为硬约束引入采光优化，让结果面向老人、儿童和日常居民都成立

七、最适合答辩与申研的一句话

本研究构建一套面向城中村节点微更新的“光权修复决策系统”，通过光环境诊断、最小干预体块重组和安全约束流线验证，量化支持空间改造方案。

八、实施步骤建议

  • 第一步：选择 1 个典型节点，建立极简现状体块模型，完成光权诊断
  • 第二步：划分保留区、可调整区、可植入区，建立最小干预的体块重组规则
  • 第三步：生成 2 至 3 组候选方案，对比居住采光、街道采光、公共活动面与安全性
  • 第四步：在不同人群条件下进行路径验证，形成方案优先级排序
  • 第五步：将结果翻译为设计图纸、节点模型和论文图表，构成完整科研闭环
