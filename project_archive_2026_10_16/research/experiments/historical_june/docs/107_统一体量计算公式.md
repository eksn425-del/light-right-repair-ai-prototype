# 107_统一体量计算公式

## 高度削减规则

本轮候选操作统一为“双建筑低干预减高 / 上部退台候选”。规则模型的高度削减为：

`h_new = max(3.0 m, h_original - min(3.0 m, 0.25 × h_original))`

即每栋被选建筑最多削减 3 m，且最低保留高度不低于 3 m。

## 规则模型体量

规则整体减高模型的削减体量为：

`V_removed = A_footprint × (h_original - h_new)`

其中：

- `A_footprint`：来自 `canonical_site_v2` 的规范建筑 footprint 面积，单位 m²；
- `h_original`：`canonical_buildings.csv` 中的建筑高度，单位 m；
- `h_new`：上述高度削减规则得到的新高度，单位 m；
- `V_removed`：真实干预体量，单位 m³。

双建筑候选的总干预体量为两栋建筑削减体量之和。

## 设计转译模型体量

设计转译模型保留底层 3 m 街巷界面，并将上部体量按中心缩放形成退台。为便于与规则模型公平比较，本轮设计转译模型控制为与对应规则模型相同的削减体量：

`A_upper / A_footprint = (h_new - h_base) / (h_original - h_base)`

其中 `h_base = min(3.0 m, h_original)`。

这意味着设计转译模型不是简单整体减高，而是在保持相同削减体量预算下改变削减位置。论文中不得把规则模型收益直接归因于设计转译模型，必须以 HB-Radiance 复算结果分别报告。
