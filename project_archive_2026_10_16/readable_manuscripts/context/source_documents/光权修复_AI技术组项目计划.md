1.3 洪禄的Vibe Coding工作范围（超出项目本身）

以下任务均通过Vibe Coding完成，体现架构师能力，不需要亲自做繁琐事：

团队任务看板（Web App）：成员登录后看本周任务、标记进度、上传文件。史天一和余丹验收，洪禄看全局。Week 1完成。

算法A / B / C 核心代码（Python）：体素化脚本、光照评价函数、模拟退火寻优、安全约束路径。用Cursor生成，与黄阳洋联调。

Banana批处理脚本：输入SU白模截图文件夹 → 自动调用Banana API批量生成效果图 → 按规范命名输出。供余丹使用，无需手动逐张操作。

论文数据可视化脚本：读取算法输出的CSV，自动生成热力图/对比柱状图/安全路径覆盖图，直接嵌入论文。

会议纪要自动整合脚本：扫描谢妍上传的Markdown会议记录，自动汇总为周报格式发给导师。

五一考察任务清单Web页：一个轻量页面，列明每个成员在现场需要拍摄/测量的具体内容，现场直接手机查看勾选。

白模文件：节点编号_段落编号_版本_日期.obj（例：node01_seg3_v2_0510.obj）

会议纪要：meeting_日期_主题.md（例：meeting_0415_kickoff.md）

论文章节草稿：paper_章节名_版本_日期.docx（例：paper_method_v2_0615.docx）
