二、核心问题与三大创新点

2.1 核心研究问题

城中村「光权—密度—安全」三者冲突下的微更新决策问题：如何在不拆除现有建筑的前提下，通过最小干预的体块重组，同时改善居住采光与街道采光，同时保障老人、儿童和日常居民的安全通行——并把这套判断过程变成可解释、可量化、可在其他城中村复用的空间决策依据。

2.2 三大创新点（与现有研究的明确边界）

创新点① | 「光权诊断—修复—验证」闭环系统——从分析工具到决策工具

现有差距：Rhino/Revit/SU插件能做日照分析，但只能告诉设计师「哪里暗」，不能输出「在哪里做什么操作可以最有效率地改善」。现有研究停留在诊断层，无法闭环到决策层。

本研究的跨越：算法A诊断「哪里最差、哪里有潜力成为光通道」→ 算法B在诊断结果基础上生成「最小干预体块重组方案」→ 算法C验证方案是否真正改善居民通行安全。三层构成完整闭环，这是本研究的系统性贡献。

创新点② | 「减法+重组+加法」最小干预体块重组算法——回应「越加越挡」的现实质疑

现有差距：现有体素化空间生成研究几乎都针对「空白场地」（新建场景），在「已有密集建筑缝隙中寻优」这一植入型场景下，几乎没有系统性研究。更重要的是，单纯「加模块」在高密度城中村会加剧遮挡，算法逻辑上站不住。

本研究的创新：算法B的操作集不只是「加」，而是三类操作联合寻优：减法（切角、退台、打通缝隙、拆违）、重组（灰空间腾挪、局部功能重排）、加法（插入方盒子、连桥、公共平台）。优化目标函数 = 居住采光提升 + 街道采光提升 + 公共活动面增加 + 流线多样性提升，同时减去原有功能损失、新遮挡惩罚、安全风险惩罚。这是专门为「既有密集环境」设计的体块寻优算法。

创新点③ | 安全作为硬约束引入采光优化——让结果面向所有人成立

现有差距：现有采光优化研究几乎不考虑「改造后方案对不同人群是否安全可达」。一条「更亮的路」如果需要走上坡度过陡的连桥、通道净宽不足、无护栏高处，对老人、儿童就是不可用的方案。这是建筑设计领域常被忽视的伦理漏洞。

本研究的创新：算法C遵循「先硬约束，再软优化」原则。硬约束包括：坡度超阈值/台阶过陡/通道净宽不足/无护栏高处/夜间照明不足不能走。在满足全部硬约束的路径集合中，再按光照时长、阴影压抑感、绕行成本做软优化。这与鼓浪屿项目「温度优先路径」形成哲学呼应：不追求最快或最亮，追求对每一个人都安全。

四、三层算法框架（技术说明）

算法A——诊断层（输入层，不是创新核心）

要素

说明

输入

节点01/07极简白模（史天一建立）；厦门纬度24.5°N；时间参数（冬至日8:00-16:00）；街道朝向；立面/窗面位置

处理

射线投射法计算每个体素单元的受光时长；识别阴影压抑区（<1h/day的体素集合）；识别潜在光通道（相邻建筑间的虚空体素中具有高SVF的缝隙）

输出

底层街道受光分布热力图；立面受光时长分布；阴影压抑区坐标集（作为算法B的输入）；潜在光通道位置列表

关键意义

不是为了展示「会做日照分析」，而是为算法B提供决策依据：哪里最需要修复，哪里有潜力被打开

算法B——决策层（核心创新）

要素

说明

输入

算法A输出的阴影压抑区 + 潜在光通道；体素矩阵中标注「实体/可调整/可植入」的三类区域；场地约束（保留主流线、保留现有建筑轮廓）

三类操作集

减法：在「可调整区」寻找切角/退台/打通缝隙的最优位置；重组：识别可腾挪的灰空间和闲置功能区；加法：在「可植入区」寻找方盒子/连桥/平台的最优坐标

目标函数

最大化（居住采光提升 + 街道采光提升 + 公共活动面增加 + 流线多样性）减去（原有功能损失 + 新增遮挡惩罚 + 结构改造成本 + 安全风险惩罚）

优化算法

模拟退火（Simulated Annealing）；用Vibe Coding（Python）实现；输出2-3组Pareto最优候选方案

输出

每组方案的体素坐标集（减法位置+加法位置）；各方案的目标函数得分对比表；供算法C验证的方案路网图

算法C——验证层（安全闭环）

要素

说明

输入

算法B输出的候选方案路网图；人群类型参数（老人/儿童/普通居民）

硬约束（先筛除不安全路径）

坡度>8%不能走；台阶高度>16cm不推荐；通道净宽<1.2m不能走；无护栏高处（>1m）不能走；夜间照明<5lux不能走

软优化（在安全路径集合内寻优）

光照时长（全程受光时间越长越好）；阴影压抑感（连续阴影段越短越好）；拥堵程度；绕行成本；与目的地距离

关键逻辑

连桥/平台只是候选路径之一，不是强制路径。只有当连桥比地面路径更安全、更明亮时，算法才会推荐它——否则地面路径优先

输出

每组方案在不同人群条件下的安全路径推荐；方案优先级排序；最终推荐方案的定量指标（采光提升幅度+安全路径覆盖率）
