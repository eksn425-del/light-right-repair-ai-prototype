二、如何运行当前 demo

进入项目目录：

cd E:/AI项目/light_equity_project

运行 toy street demo：

python main.py --dataset sample_toy_street

如果想重新生成 toy 数据：

python main.py --dataset sample_toy_street --regenerate-toy

真实灌口数据未来放入：

E:/AI项目/light_equity_project/data/real_guankou/

然后运行：

python main.py --dataset real_guankou

当前 real_guankou 里还是占位文件，所以运行真实数据时会提示 site_model.obj 没有顶点，需要建筑组替换为 SketchUp 导出的真实白模。

三、当前版本的定位

这是“工程骨架版”，不是最终算法精度版。

它现在解决的是：

1. 目录稳定
2. 接口稳定
3. CSV 字段稳定
4. 输出文件稳定
5. toy 数据可完整跑通
6. 后续真实 OBJ 和 CSV 可以替换接入

它暂时不追求：

1. 专业光环境软件级精度
2. 复杂建筑布尔运算
3. 高精度路径网络
4. Web 平台
5. 数据库
6. Rhino / Grasshopper / Ladybug / Unity 强依赖

四、当前简化假设

1. 建筑以轴对齐盒子和 CSV 包围盒表达。
2. 算法 A 使用 2.5D 简化遮挡判断，不是真实体素射线追踪。
3. 算法 B 的 candidate OBJ 是参考改造框体，不是真实布尔切割后的建筑模型。
4. 算法 C 的路线是节点间简化路线，不是完整道路网络。
5. final_report 中 manual_design 是占位数据，等建筑组提交人工方案后替换。
