# 文献综述种子：光环境优化与人机协同设计

更新时间：2026-06-01

说明：这份文件是后续写论文综述的“种子清单”，不是最终参考文献格式。当前重点是帮项目确定理论位置：太阳可达性、性能导向设计、参数化/生成式优化、人机协同。

## 1. 太阳可达性与 Solar Envelope

Ralph Knowles 的 Solar Envelope 思想适合作为本项目的理论底座之一。它强调城市体量不能只看单栋建筑，而要看建筑高度、街道宽度、街道方向和太阳路径之间的关系。对于旧街区更新来说，这能支持“光权修复”不是单纯增加设施，而是对密集街区中公共光照权益的再分配。

可用论点：

- 光照是一种公共空间资源；
- 建筑体量调整会影响邻里与街道的太阳可达性；
- 体量控制应服务于关键时段、关键公共空间的日照保障；
- 本项目的减法、退台、采光缝可以被解释为低成本的太阳可达性修复策略。

种子来源：

- Ralph Knowles, solar envelope / solar access design.
- Low-tech Magazine 对 Solar Envelope 的通俗解释。
- “Reverse solar envelope method” 相关研究，可作为更现代的体量生成参考。

## 2. 环境性能导向设计

Ladybug Tools 这类工具说明了建筑环境分析已经从后期校核转向早期设计反馈。我们的项目不直接依赖 Rhino / Grasshopper / Ladybug，但方法上接近它们：在设计早期用日照、阴影、太阳路径等指标辅助体量判断。

可用论点：

- 环境模拟不应只在方案完成后验证，而应进入设计生成过程；
- 早期低精度模拟仍有价值，因为它能帮助筛选方向；
- 低门槛工具适合本科团队和真实课程项目；
- 本项目用 Python 替代商业/复杂插件，目的是降低协作门槛。

种子来源：

- Ladybug Tools 官方资料：太阳路径、阴影、太阳可达性、日照小时分析。
- Ladybug + Honeybee 相关论文与工具说明。

## 3. 性能驱动的体量优化

近年的 building massing optimization 和 performance-based generative design 研究说明，建筑体量可以被参数化，并通过日照、能耗、视野、密度等指标进行迭代优化。但很多研究偏向新建项目或高精度模拟，本项目的特点是旧街区、有不可动边界、有公共服务和风貌限制。

可用论点：

- 体量优化不是追求单一最高分，而是生成可比较的候选；
- 旧街区更新需要把性能指标与人工约束结合；
- “最小干预”比“最大优化”更符合老街区更新；
- 算法输出应是设计讨论对象，而不是自动最终方案。

种子来源：

- EvoMass / early-stage performance-based building massing optimization。
- Performance-based urban block generative design。
- Solar access optimization / reverse solar envelope。

## 4. Human-in-the-loop 与建筑 AI 协作

会议后项目更适合放在 human-in-the-loop 的框架下：AI 不判断文化价值、产权和公共服务边界，而是在人工给定的干预等级内做诊断、筛选和迭代。

可用论点：

- AI 适合处理重复计算、方案枚举、指标比较；
- 人适合处理价值判断、场地伦理、功能策划和最终设计表达；
- 人机协同设计的关键不是“AI 比人更好”，而是“人如何把约束转成算法可执行规则”；
- 干预等级表是本项目从建筑判断走向算法输入的关键接口。

种子来源：

- Human-AI Collaboration in Architectural Design Education: Towards a Conceptual Framework。
- Designing successful Human-AI Collaboration for Creative-Problem Solving in Architectural Design。
- Generative AI-enhanced human-AI collaborative conceptual design review。

## 5. 与本项目最匹配的论文叙事

建议论文综述采用四段式：

1. 老街区更新需要兼顾公共空间、文化延续、慢行安全和空间活力。
2. 光照/日照可达性是老街区空间质量的重要但常被弱化的指标。
3. 性能导向和参数化工具可以帮助早期设计判断，但直接套用高精度平台成本较高。
4. 因此，本研究提出低门槛 Python 流程：人工定义干预边界，AI 进行采光诊断、最小干预候选生成和约束验证。
