# 给网页端 AI 的审查说明

## 审查目的

请你审查随附的《01_完整文章母版_待审查.docx》，判断它目前是否适合作为“中文导师审阅定稿版”，并提出应如何诚实修改。

注意：这份 Word 是当前论文母版，不是已经完成全部新增实验后的定稿。请不要默认其中所有结论已经被新增验证支持。

## 论文拟定方向

论文题目建议调整为：

《旧街区早期更新中的直射日照可达性诊断与低干预候选生成：规则启发式工作流研究——以厦门灌口沿湖休闲片区为例》

论文应定位为：

面向旧街区早期更新的“地面点位直射日照可达性诊断”和“低干预候选生成”的规则启发式工作流。

它不应被表述为：

- 专业日照审查；
- 高精度采光模拟；
- AI 自动生成唯一最优方案；
- 可直接替代设计师判断；
- 已证明显著环境性能提升；
- 可普适泛化到所有场地。

## 我方复核得到的关键事实

我方基于原始数据、代码、CSV、OBJ/SKP/DXF 与论文母版做过一次真实性审查和补充实验尝试，结论是：目前不应直接产出“中文导师审阅定稿版”，只能产出“导师预审/问题诊断版”。

主要原因如下：

1. 原论文中的 C6/C33 不宜继续作为唯一推荐方案。

2. Python 2.5D 规则模型重新枚举双建筑候选后，排序第一的候选是 C13/C24。

3. 2.5D 模型下：
   - C13/C24 的低直射日照区面积下降约 162 m²；
   - C6/C33 的低直射日照区面积下降约 9 m²；
   - C13/C24 位于 Pareto 前沿；
   - C6/C33 不在 Pareto 前沿。

4. 但独立三维参考模拟的方向并不完全支持 2.5D 排名：
   - C6/C33 的参考模拟低直射日照区面积下降约 54 m²；
   - C13/C24 的参考模拟低直射日照区面积下降约 18 m²；
   - C13/C24 的点位改善方向一致率约 0.479；
   - C6/C33 的点位改善方向一致率约 0.410。

5. 这说明：2.5D 规则模型和独立三维参考模型之间存在重要分歧。当前证据不足以支持“唯一最优方案”或“定稿结论”。

6. Rhino / Grasshopper / Ladybug / Honeybee / Radiance 路径在本机尚未完整可用，因此不能声称完成了正式 Ladybug/Radiance 独立验证。已有参考模拟只能作为一次独立三维射线追踪复核尝试。

7. 建筑设计转译版本已经做过简化建模与复核尝试，但仍不足以把“整体减高规则模型”的效果直接归因于真实建筑设计方案。

## 请重点审查的问题

请围绕以下问题给出直接、可执行的审查意见：

1. 这篇论文目前是否能作为“中文导师审阅定稿版”？

2. 如果不能，应如何降级为“导师预审稿”或“问题诊断稿”？

3. 原文中哪些表述存在夸大风险，例如“显著改善”“最优方案”“高精度模拟”“光权修复”等？

4. C6/C33 是否应从“最终推荐方案”降级为“候选区间中的一个方案”？

5. C13/C24 是否也不能作为唯一最终方案，只能作为规则模型下的高分候选？

6. 独立验证结果与 Python 规则模型结果不一致时，结果章节和结论应如何改写？

7. 论文应如何清楚说明：
   - 数据来源；
   - 参数设置；
   - 算法 A 的 2.5D 遮挡逻辑；

   - 公平基线；
