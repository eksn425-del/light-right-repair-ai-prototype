# Anonymous manuscript source

Compile `manuscript.tex` with PDFLaTeX, BibTeX, PDFLaTeX, PDFLaTeX, or run `build_portable.sh` in a standard TeX installation. Required packages include newtx, tex-gyre, graphicx, booktabs, amsmath, placeins and hyperref. `manuscript.bbl` is included for bibliography portability.

The unchanged LLNCS class and splncs04 bibliography style come from the current official Springer Computer Science Proceedings template. Preserve their embedded copyright and license notices. Official source: https://link.springer.com/series/558/information-for-authors-and-editors . Font files and the publisher's sample documents are not included.

The PDF/SVG figures are deterministic plots of frozen aggregate data, generated with Matplotlib; the PDF files are embedded directly in the manuscript. No raster image is concealed inside the vector plot files. PNG exports are 300 dpi.

The manuscript is anonymous and prepared for author review. Its AI-assistance disclosure is intentional. Author approval and confirmation of the conference's conflicting anonymous-disclosure placement instructions are still required. This source bundle is not a submission confirmation or a public-data license.
