## Corrections that must survive editing

- Original production sorting is score/A/H descending. There are no exact score ties. Natural numeric pair order is a separate cohort top-K tie protocol.
- All ten score-selected pairs have archived rule-level HB results. Only C9/C24, C9/C15 and C9/C13 among the top ten have translated-design evidence. The first two have contained corrections; C9/C13 reuses its already-contained unchanged result.
- Review membership is 10 Top10 + 12 nonzero-benefit A/V front + 2 historical + 2 controls − 3 Top10/front overlaps = 23. Review is not random sampling.
- N is identically zero; the normalized score contributes a constant 0.05. It does not distinguish these candidates.
- The 20-case cohort is same-site outcome-blind coverage, not a random or multi-site external test.
- C9/C24 and C13/C24 adverse events were caused by erroneous outside-footprint generated walls. They are not unavoidable side effects of subtraction.
- Four corrected translations had no adverse events on the fixed model/grid/rays. C9/C13 was already contained and is not an eleventh new run.
- Nominal rule volume, whole-scene union reduction and translated volume are different. No volume matching or verified demolition quantities are claimed.
- The 482.927 runtime ratio is historically measured between two unindexed single-thread same-primitive implementations. The current cloud work reanalyses those measurements; it did not run the site solver or this benchmark again.
- Approximate DXF bounding-box/shared footprints, actual OBJ discrepancies, 3 m grid, 0.1 m sensors, 3 h threshold, 16 half-hour samples, assumed north zero, constant WEA carrier, different pvlib/HB rays and restricted raw data remain explicit.
