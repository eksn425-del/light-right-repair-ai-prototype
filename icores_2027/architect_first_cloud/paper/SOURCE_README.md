# Anonymous manuscript source

Run `sh build_portable.sh` with a normal TeX Live or MiKTeX distribution containing newtx and tex-gyre. The source bundle includes llncs.cls, splncs04.bst, source TeX/BibTeX, editable table includes, generated vector figure PDFs and build script. No raw geometry/coordinates or private source inputs are bundled.

The present cloud installation has missing default filename/format maps. Its existing workspace-only TeX configuration was used, rather than altering system settings. Full build commands and logs are in qa/. On a normal TeX installation, no cloud-specific paths should be needed.

The PDF is anonymous. This source package is for private author review; paths, provenance, QA logs and Chinese explanations are not anonymous submission supplements. Only the approved anonymous PDF is intended for initial upload. No rights/authorship/conflict/single-submission declaration is supplied on the authors' behalf.
